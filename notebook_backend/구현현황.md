## 🎨 프로젝트가 뭐예요?

**NameTag**는 **AI(인공지능)가 자동으로 브랜드를 만들어주는 서비스**입니다.

### 쉽게 말하면:
마치 **마법사**처럼, 당신이 원하는 스타일을 말해주면 👉 AI가 쏘옥 **로고와 브랜드명을 만들어주는** 거예요! ✨

예를 들어:
- 📝 당신: "친환경 쇼핑몰이고, 모던하고 신뢰할 수 있는 느낌이 좋아요"
- 🤖 AI: "좋아요! 그럼 '지속가능마켓'이라는 브랜드명 어때요? 로고는 초록색의 유기적인 모양으로 해볼게요!"
- 🎨 결과: 로고가 SVG 파일로 저장됨

   └─ "1번 브랜드로 할게요!"

### 3️⃣ SVG 로고 저장 시스템 ⭐ (가장 중요!)
```
상태: ✅ 완성됨 (코드 작성 완료)
```

**SVG가 뭐예요?**
- **SVG** = 벡터 이미지 (수학으로 만든 이미지)
- **PNG** = 사진처럼 저장된 이미지
- 차이점: SVG는 아무리 커도 흐릿해지지 않음 (마치 지우개 손잡이 크기 같음)

**현재 구현된 코드:**

```python
# 단계 1️⃣: AI에게 SVG 코드 만들어달라고 요청
prompt = "SVG 형식의 로고를 만들어줘"

# 단계 2️⃣: AI가 SVG 코드 생성
response = ai.generate("SVG 코드를 JSON으로 줘")
# 결과: {
#   "logo_svg": "<svg>...</svg>"
# }

# 단계 3️⃣: SVG 파일로 저장
with open(f"logo/logo_{브랜드명}_{시간}.svg", "w") as file:
    file.write(svg_코드)
print("✅ SVG 파일이 저장되었어요!")
```

**저장되는 위치:**
```
📁 logo/
   ├─ logo_지속가능마켓_20260519_103000.svg
   ├─ logo_따뜻한마켓_20260519_110000.svg
   └─ (여기에 계속 저장됨)
```

**왜 SVG를 썼어요?**
- 💾 용량이 아주 작음 (KB, PNG는 MB)
- 📏 아무리 크게 해도 깨끗함
- 🌐 웹 사이트에 올리기 좋음
- ✏️ 나중에 색상 수정도 가능
