# Name Tag — 로고 & 캐릭터 생성 프롬프트 시스템

> **이 문서의 목적:** 사용자의 브랜드 인풋을 받아 
> 로고와 캐릭터 이미지를 생성하는 프롬프트 체계를 정의한다.  
> **적용 패키지:** Package A (Identity) — 로고, 서체, 캐릭터 생성  
> **연동 패키지:** Package B (Visuality) — 목업 적용 시 이 프롬프트의 결과물 사용  
> **핵심 원칙:** 사용자가 입력한 브랜드 맥락이 모든 시각 요소를 결정한다.

---

## 아이템 코드 시스템

Name Tag의 모든 생성물은 아이템 코드로 관리된다.  
코드 구조: `NT - [패키지] - [유형] - [스타일] - [번호]`

```
NT   = Name Tag
A    = Package A (Identity)
B    = Package B (Visuality)

유형:
LG   = Logo (로고)
CH   = Character (캐릭터/마스코트)
TY   = Typography (서체 조합)
MK   = Mockup (목업)

스타일:
GEO  = Geometric (기하학적)
ORG  = Organic (유기적)
ABS  = Abstract (추상적)
MNM  = Minimalist (미니멀)
BLD  = Bold (강한)
SFT  = Soft (부드러운)

예시:
NT-A-LG-GEO-001  = Package A, 로고, 기하학 스타일, 첫 번째 시안
NT-A-CH-SFT-002  = Package A, 캐릭터, 소프트 스타일, 두 번째 시안
```

## 1. 사용자 입력 변수 시스템

사용자가 Name Tag에 입력하는 값들이 프롬프트의 변수를 자동으로 채운다.  
아래 변수들이 모든 생성 프롬프트에 공통으로 사용된다.

---

### 필수 입력 변수 (사용자가 반드시 입력)

```
[BRAND_NAME]      브랜드/서비스 이름
                  예: "Brewly", "핏터", "Leafy"

[BRAND_TOPIC]     사업 주제 또는 업종
                  예: "수제 커피 구독 서비스", 
                      "운동 습관 추적 앱",
                      "친환경 식물 배달"

[CORE_VALUE]      브랜드가 전달하고 싶은 핵심 가치 1~2개
                  예: "신뢰와 정밀함", "따뜻함과 지속 가능성"

[TARGET_MOOD]     원하는 브랜드 감성 (아래 무드 테이블 참조)
                  예: "모던 & 신뢰", "따뜻 & 친근", "미니멀 & 프리미엄"
```

---

### 선택 입력 변수 (사용자가 선택하거나 비워두면 자동 추천)

```
[BRAND_COLOR]     선호 색상 또는 색상 코드
                  비워두면: [TARGET_MOOD]에 맞는 색상 자동 추천
                  예: "#2D6A4F" 또는 "딥그린 계열"

[FONT_STYLE]      서체 느낌 선호도
                  비워두면: [TARGET_MOOD]에 맞는 서체 자동 추천
                  선택지: 기하학적 산세리프 / 클래식 세리프 / 
                          손글씨 느낌 / 굵고 강한 / 얇고 우아한

[SYMBOL_TYPE]     심볼 스타일 선호도
                  비워두면: [BRAND_TOPIC]에 맞는 심볼 자동 생성
                  선택지: 기하학적 / 유기적 / 아이콘형 / 
                          추상적 / 레터마크(이니셜 기반)

[LOGO_TYPE]       로고 구성 방식
                  선택지: 심볼+텍스트 조합 / 심볼만 / 
                          텍스트만 / 배지형
                  기본값: 심볼+텍스트 조합

[BACKGROUND]      배경 색상
                  기본값: 흰색 (#FFFFFF)
                  선택지: 흰색 / 검정 / 브랜드 색상 / 투명
```

## 3. 로고 생성 프롬프트 — 마스터 템플릿

아래는 모든 로고 생성에 사용되는 마스터 프롬프트다.  
`[변수]` 부분이 사용자 입력 또는 자동 매핑 값으로 채워진다.

---

### 마스터 로고 프롬프트 (영문 — 이미지 생성 AI용)

```
You are a professional logo designer specializing in brand identity 
for early-stage startups. Create a clean, vector-style logo with 
the following precise specifications:

**BRAND CONTEXT**
Brand Name: [BRAND_NAME]
Industry/Topic: [BRAND_TOPIC]
Core Values: [CORE_VALUE]
Brand Mood: [TARGET_MOOD]

**SYMBOL DESIGN**
Style: [SYMBOL_TYPE] — design a symbol that visually represents 
[BRAND_TOPIC] through [SYMBOL_TYPE] shapes and forms.
The symbol must feel original, not generic or stock-image-like.
It should communicate [CORE_VALUE] at first glance.
Avoid literal representations — use abstraction to elevate meaning.

**TYPOGRAPHY**
Font style: [FONT_STYLE] typeface (similar to [FONT_REFERENCE])
Brand name "[BRAND_NAME]" centered below the symbol.
Letter spacing: slightly wide for modern feel.
Weight: [FONT_WEIGHT] — balanced with symbol weight.
Text size ratio to symbol: approximately 1:2 (text:symbol height).

**COLOR**
Primary: [BRAND_COLOR]
Background: [BACKGROUND]
Use a maximum of 2 colors total. 
No gradients unless specified.
High contrast for print and digital readability.

**COMPOSITION**
Logo type: [LOGO_TYPE]
Alignment: centered, perfectly symmetrical.
Padding: equal whitespace on all sides.
The symbol and text must feel like one unified system, not two 
separate elements placed together.

**QUALITY REQUIREMENTS**
- Vector-style sharp edges, no blur or soft shadows
- Matte finish texture (no gloss or metallic shine)
- High contrast, legible at both 16px and 500px sizes
- Clean, minimal — no decorative elements beyond the core concept
- White space is intentional and generous
- Final output should feel like a professional brand identity, 
  not a generic AI-generated logo

**BACKGROUND**
[BACKGROUND] — completely flat, no texture or noise.
```

---

### 마스터 로고 프롬프트 (한국어 — Gemini/기타 한국어 지원 AI용)

```
당신은 초기 스타트업 브랜드 아이덴티티를 전문으로 하는 
전문 로고 디자이너입니다. 아래 사양에 따라 
깔끔하고 벡터 스타일의 로고를 생성해주세요.

**브랜드 맥락**
브랜드명: [BRAND_NAME]
업종/주제: [BRAND_TOPIC]
핵심 가치: [CORE_VALUE]
브랜드 무드: [TARGET_MOOD]

**심볼 디자인**
스타일: [SYMBOL_TYPE]
[BRAND_TOPIC]을 [SYMBOL_TYPE] 형태로 시각화한 심볼을 디자인하세요.
심볼은 [CORE_VALUE]를 첫눈에 전달해야 합니다.
진부한 스톡 이미지 느낌이 아닌, 독창적인 형태를 사용하세요.
직관적인 표현보다 추상적 표현으로 품격을 높이세요.

**타이포그래피**
서체 스타일: [FONT_STYLE] 계열 (예: [FONT_REFERENCE] 유사)
심볼 아래 중앙 정렬로 '[BRAND_NAME]' 텍스트 배치
자간: 현대적 느낌을 위해 약간 넓게
굵기: [FONT_WEIGHT] — 심볼 굵기와 균형 유지
텍스트와 심볼의 높이 비율: 약 1:2

**색상**
주색상: [BRAND_COLOR]
배경: [BACKGROUND]
최대 2가지 색상만 사용
그라디언트 없음 (별도 지정 시 제외)
인쇄 및 디지털 모두에서 높은 대비 유지

**구성**
로고 유형: [LOGO_TYPE]
정렬: 중앙, 완벽한 대칭
여백: 사방 균등한 여백
심볼과 텍스트는 각각 분리된 요소가 아닌 
하나의 통합된 시스템으로 느껴져야 합니다.

**품질 요구사항**
- 벡터 스타일의 선명한 가장자리, 블러 없음
- 매트 마감 질감 (광택이나 금속 광택 없음)
- 16px와 500px 모두에서 가독성 유지
- 핵심 컨셉 외 장식 요소 없음
- 여백은 의도적으로 넓게
- 결과물은 AI 생성 로고가 아닌 
  전문 브랜드 아이덴티티처럼 느껴져야 함

**배경**
[BACKGROUND] — 완전히 평평하게, 텍스처나 노이즈 없음
```

## 4. 로고 스타일별 세부 프롬프트

[SYMBOL_TYPE]에 따라 아래 섹션이 마스터 프롬프트에 추가된다.

---

### Style A — 기하학적 (Geometric) `NT-A-LG-GEO`

```
**SYMBOL SPECIFICATION — GEOMETRIC**
Construct the symbol using only basic geometric forms: 
circles, lines, triangles, squares, hexagons.
The geometry must have a mathematical precision — 
every angle intentional, every proportion calculated.
Symmetry: [radial / bilateral / asymmetric with balance]
Line weight: consistent throughout, no variation.
Negative space: use it as an active design element.

Avoid: rounded corners unless part of the concept,
       organic curves, hand-drawn qualities.

추가 (한국어):
완벽한 수학적 정밀함으로 기본 기하학 도형만 사용합니다.
모든 각도와 비율이 의도적으로 계산된 느낌.
여백(네거티브 스페이스)을 적극적인 디자인 요소로 사용.
```

---

### Style B — 유기적 (Organic) `NT-A-LG-ORG`

```
**SYMBOL SPECIFICATION — ORGANIC**
The symbol uses fluid, natural curves inspired by 
[BRAND_TOPIC]-related natural forms.
Shapes feel hand-crafted but refined — 
not perfectly mathematical, but not sloppy.
Movement: the form should suggest gentle flow or growth.
Avoid: harsh angles, perfect circles, rigid geometry.
Think: leaves, water flow, growth rings, 
       breath, natural movement.

추가 (한국어):
[BRAND_TOPIC]에서 영감받은 유기적 자연 곡선 사용.
손으로 그린 느낌이지만 세련되게 다듬어진 형태.
딱딱한 각도나 완벽한 원형 피하기.
성장, 흐름, 자연적 움직임을 연상시키는 형태.
```

---

### Style C — 미니멀 라인 (Minimalist Line) `NT-A-LG-MNM`

```
**SYMBOL SPECIFICATION — MINIMALIST LINE**
Single continuous line or maximum 3 separate strokes.
Line weight: [thin: 1-2pt / medium: 3-4pt / thick: 5-6pt]
The symbol communicates the brand concept 
with absolute economy of form — nothing added, 
nothing removable without losing meaning.
Inspiration: Japanese Enso, Swiss International Style.
Avoid: filled shapes, multiple elements, complexity.

추가 (한국어):
단일 연속선 또는 최대 3개의 선으로만 구성.
절대적인 형태의 경제성 — 더할 것도, 뺄 것도 없는 상태.
채워진 도형 없이 선(아웃라인)만으로 표현.
스위스 국제 타이포그래피 스타일 참조.
```

---

### Style D — 레터마크 (Lettermark) `NT-A-LG-LTR`

```
**SYMBOL SPECIFICATION — LETTERMARK**
Use the initial letter(s) of [BRAND_NAME]: "[INITIALS]"
Transform the letterform into a custom logotype — 
not a standard font character, but a redesigned letterform.
The letter shape should embed a visual metaphor 
related to [BRAND_TOPIC].
Counter spaces (the holes inside letters) are 
actively designed, not accidental.
Avoid: using an unmodified font character as the logo.

추가 (한국어):
[BRAND_NAME]의 이니셜 '[INITIALS]'을 사용.
표준 폰트 문자가 아닌, 커스텀 레터폼으로 재설계.
문자 내부의 카운터 공간(구멍)도 의도적으로 디자인.
[BRAND_TOPIC]과 관련된 시각적 메타포를 문자 안에 내재.
```

---

### Style E — 아이콘형 (Iconic) `NT-A-LG-ICN`

```
**SYMBOL SPECIFICATION — ICONIC**
A simplified, iconic representation of the core concept 
behind [BRAND_TOPIC].
Reduction level: imagine simplifying a photograph into 
a 5-stroke icon — that level of abstraction.
The icon should be recognizable at 16x16px.
Style reference: app icons, wayfinding symbols, 
                 Olympic pictograms.
Avoid: photorealistic detail, more than 5 visual elements,
       text integrated into the symbol.

추가 (한국어):
[BRAND_TOPIC]의 핵심 개념을 단순화한 아이콘 형태.
16x16px 크기에서도 인식 가능한 수준의 단순화.
앱 아이콘, 안내 표지판, 올림픽 픽토그램 수준의 추상화.
5개 이상의 시각 요소 사용 금지.
```

## 5. 캐릭터 생성 프롬프트 — 마스터 템플릿

Package A의 캐릭터/마스코트 생성에 사용되는 마스터 프롬프트.  
캐릭터는 브랜드의 "얼굴"이 되므로, 로고보다 더 풍부한 인격 설정이 필요하다.

---

### 캐릭터 기본 설정 변수

```
[CHAR_CONCEPT]    캐릭터의 기반 컨셉 (사람/동물/사물/추상)
                  예: "작은 로봇", "커피 원두", "바람을 타는 씨앗"

[CHAR_PERSONALITY] 캐릭터의 성격 키워드 3개
                  예: "친근함, 똑똑함, 엉뚱함"
                       "차분함, 신뢰, 따뜻함"

[CHAR_AGE_FEEL]   캐릭터가 주는 나이대 느낌
                  선택지: 어린이 / 청소년 / 청년 / 중장년 / 나이 초월
                  (실제 나이가 아닌 느낌)

[CHAR_STYLE]      일러스트 스타일
                  선택지: 플랫 일러스트 / 2.5D / 픽셀아트 / 
                          손그림 느낌 / 3D 렌더 / 벡터 라인
```

### Type 1 — 의인화 사물 (Anthropomorphized Object) `NT-A-CH-OBJ`

```
**CHARACTER TYPE: ANTHROPOMORPHIZED OBJECT**

- Expressive eyes (the most important feature)

  * Friendly: larger head (60% of body), round shapes
  * Professional: balanced proportions, upright posture
  * Playful: exaggerated features, dynamic tilt

The object's original form must still be clearly recognizable 
after anthropomorphization.

커피 브랜드    → 커피컵에 눈과 팔 (컵 형태 유지)
```

### Type 4 — 추상 캐릭터 (Abstract Character) `NT-A-CH-ABS`

```
**CHARACTER TYPE: ABSTRACT CHARACTER**
Not based on any recognizable real-world form.
The character is built from the brand's core visual elements:
shapes from the logo, colors from the brand palette.

It must feel alive and personable despite being abstract.
Achieve personality through:
- Movement implied by shape (pointed = energetic, round = calm)
- Eye placement (even abstract characters need some eye analog)
- Color contrast to show "face" area vs "body" area

Reference: Abstract characters from tech brands 
(Duolingo's original concept, early Twitter bird geometry)

추상 캐릭터 설계 원칙:
현실 세계의 형태에 기반하지 않음.
브랜드 로고의 핵심 형태 요소를 캐릭터로 발전.
'눈'의 역할을 하는 요소는 반드시 포함 (추상적이어도).
형태 자체로 성격을 전달 (뾰족 = 에너지, 둥근 = 편안함).
```
